# Night-ER

夜間救急を体験するReact製シミュレーターです。22:00から翌03:00までを現実10分で遊ぶショート当直と、17:00から翌08:00までを現実30分で遊ぶフル当直を選択できます。
通常4床の救急ベッドを管理しながら受入要請に応答し、診断・初期治療を進めます。
「医学生向け」と「研修医・医師向け」を各120例（主要100例＋軽症20例）、合計240例収録しています。

開始時はプレイヤー名とBGMのON/OFFを設定してから、「医学生／研修医・医師」→「二次救急／三次救急」→「ショート／フル当直」の順に選択します。
当直開始前には、利用者区分と救急区分の組み合わせに応じて「医学生／研修医・医師」と院長が掛け合うチュートリアルを表示します。チュートリアルは最初の確認画面からスキップできます。
二次救急と三次救急を両方完走すると、10床へ患者を次々と自動収容するシークレット「断らない救急」が解放されます。
タイトル画面では、ゲーム専用に作成したピアノ入りアンビエントBGMと心電図モニター音を任意で再生できます。開始時にBGMをOFFにした場合も、操作や通知の効果音は再生されます。
当直中はBGMをONにした場合のみ、タイトル画面とは異なる緊張感のあるオリジナルBGMへ切り替わり、患者数・急変ゲージ・受入要請・フィーバータイムに応じてテンポと音の密度が変化します。

## 起動方法

```bash
npm install
npm run dev
```

本番ビルド:

```bash
npm run build
```

## ゲームの概要

- 現実1秒 = ゲーム内30秒
- 開始時にプレイヤー名とBGMのON/OFFを設定（設定は同じ端末・ブラウザに保存）
- タイトル画面専用のピアノ入りアンビエントBGM + 心電図モニター音（再生ON/OFF対応）
- 当直中専用の動的BGM（76〜142 BPM、患者数や赤ゲージに応じてテンポ・音数が上昇）
- 当直開始前の決定操作と、当直中の処置選択で異なる効果音を再生
- 救急隊から受入要請が入ると黒電話ベル、ベッド収容時に専用の決定音を再生
- 患者ゲージの赤色移行・ICU搬送・GOOD DOCTOR達成を専用効果音で通知
- プレイ中は明るい救急外来を背景表示し、患者数・処置・急変・搬送要請に応じてスタッフや機器が動的に変化
- 医学生／研修医・医師と院長の掛け合いによる、役割・救急区分別チュートリアル（スキップ対応）
- 医学生向け: 国試頻出疾患と救急初期対応の主要100例＋軽症20例
- 研修医・医師向け: 鑑別、蘇生、専門科連携、高エネルギー外傷を扱う主要100例＋軽症20例
- 二次救急: 一般急性疾患・軽症を中心に、自院入院または高次転送を判断
- 三次救急: 重症・複数診療科・高エネルギー外傷が約8割
- シークレット「断らない救急」: 二次・三次両方の完走で解放、10床・受入拒否なし・自動収容
- ショート当直: 22:00〜翌03:00（現実10分）
- フル当直: 17:00〜翌08:00（現実30分）
- フル当直は一時停止に対応
- 一時停止メニューから「当直を続ける」「セーブして戻る」「終了する」を選択可能
- 保存したフル当直は、同じ端末・ブラウザのタイトル画面から再開可能
- 症例完遂で「褒め」ポイント
- 受入拒否・患者急変で「残念」ポイント
- スコアが +5 を超えるとフィーバータイム
- スコアが −5 に達するとゲームオーバー

フル当直の進捗と二次／三次救急のクリア状況は、ブラウザの `localStorage` に保存されます。ブラウザのサイトデータを削除すると保存内容も失われます。

掲載内容は学習用のシミュレーションであり、実際の診療判断には使用しないでください。

## 音源クレジット

- 心電図SE: [「心電図が」](https://dova-s.jp/se/detail/162) / 稿屋 隆（DOVA-SYNDROME）
- 決定SE 33・51・53: ユーザー提供音源
- 救急隊からの受入要請（黒電話ベル）: ユーザー提供音源
- 警告SE 1・2、成功SE: ユーザー提供音源
- タイトルBGM（アンビエントパッド・ピアノ）: Night-ER用オリジナル音源（Web Audio APIによる生成）
- プレイ中BGM（ERレスキュー・パルス）: Night-ER用オリジナル音源（Web Audio APIによる生成）

## Cloudflare Pagesランキング

Cloudflare Pages FunctionsとD1を使った、利用者区分・救急区分・当直モード別のTOP 10ランキングに対応しています。開始時のプレイヤー名がリザルト画面へ引き継がれ、必要なら送信前に編集できます。

Cloudflare側で必要なD1、Bindings、Secretsの設定は [`cloudflare/README.md`](./cloudflare/README.md) を参照してください。
