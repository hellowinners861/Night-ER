# Night-ER

22:00から03:00までの夜間救急を、現実10分で体験するReact製シミュレーターです。
4床の救急ベッドを管理しながら受入要請に応答し、30症例の診断・初期治療を進めます。

## 起動方法

```bash
npm install
npm run dev
```

本番ビルド:

```bash
npm run build
```

## ゲームの概要

- 現実1秒 = ゲーム内30秒
- 症例完遂で「褒め」ポイント
- 受入拒否・患者急変で「残念」ポイント
- スコアが +5 を超えるとフィーバータイム
- スコアが −5 に達するとゲームオーバー

掲載内容は学習用のシミュレーションであり、実際の診療判断には使用しないでください。
