# Night-ER

夜間救急を体験するReact製シミュレーターです。22:00から翌03:00までを現実10分で遊ぶショート当直と、17:00から翌08:00までを現実30分で遊ぶフル当直を選択できます。
通常4床の救急ベッドを管理しながら受入要請に応答し、診断・初期治療を進めます。
「医学生向け」と「研修医・医師向け」を各120例（主要100例＋軽症20例）、合計240例収録しています。

開始時は「医学生／研修医・医師」→「二次救急／三次救急」→「ショート／フル当直」の順に選択します。
当直開始前には、利用者区分と救急区分の組み合わせに応じて「医学生／研修医・医師」と院長が掛け合うチュートリアルを表示します。チュートリアルは最初の確認画面からスキップできます。
二次救急と三次救急を両方完走すると、10床へ患者を次々と自動収容するシークレット「断らない救急」が解放されます。
タイトル画面では、ゲーム専用に作成したピアノ入りアンビエントBGMと心電図モニター音を任意で再生できます。BGMは当直開始時にフェードアウトします。
当直中はタイトル画面とは異なる緊張感のあるオリジナルBGMへ切り替わり、患者数・急変ゲージ・受入要請・フィーバータイムに応じてテンポと音の密度が変化します。

## 起動方法

```bash
npm install
npm run dev
```

本番ビルド:

```bash
npm run build
```

## ゲームの概要

- 現実1秒 = ゲーム内30秒
- タイトル画面専用のピアノ入りアンビエントBGM + 心電図モニター音（再生ON/OFF対応）
- 当直中専用の動的BGM（76〜142 BPM、患者数や赤ゲージに応じてテンポ・音数が上昇）
- 医学生／研修医・医師と院長の掛け合いによる、役割・救急区分別チュートリアル（スキップ対応）
- 医学生向け: 国試頻出疾患と救急初期対応の主要100例＋軽症20例
- 研修医・医師向け: 鑑別、蘇生、専門科連携、高エネルギー外傷を扱う主要100例＋軽症20例
- 二次救急: 一般急性疾患・軽症を中心に、自院入院または高次転送を判断
- 三次救急: 重症・複数診療科・高エネルギー外傷が約8割
- シークレット「断らない救急」: 二次・三次両方の完走で解放、10床・受入拒否なし・自動収容
- ショート当直: 22:00〜翌03:00（現実10分）
- フル当直: 17:00〜翌08:00（現実30分）
- フル当直は一時停止に対応
- 一時停止メニューから「当直を続ける」「セーブして戻る」「終了する」を選択可能
- 保存したフル当直は、同じ端末・ブラウザのタイトル画面から再開可能
- 症例完遂で「褒め」ポイント
- 受入拒否・患者急変で「残念」ポイント
- スコアが +5 を超えるとフィーバータイム
- スコアが −5 に達するとゲームオーバー

フル当直の進捗と二次／三次救急のクリア状況は、ブラウザの `localStorage` に保存されます。ブラウザのサイトデータを削除すると保存内容も失われます。

掲載内容は学習用のシミュレーションであり、実際の診療判断には使用しないでください。
