# Night-ER

夜間救急を体験するReact製シミュレーターです。22:00から翌03:00までを現実10分で遊ぶショート当直と、17:00から翌08:00までを現実30分で遊ぶフル当直を選択できます。
4床の救急ベッドを管理しながら受入要請に応答し、診断・初期治療を進めます。
「医学生向け」と「研修医・医師向け」を各50例、合計100例収録しています。

開始時は、まず「医学生」または「研修医・医師」を選び、その後にショート当直またはフル当直を選択します。
タイトル画面では、ゲーム専用に作成したピアノ入りアンビエントBGMと心電図モニター音を任意で再生できます。BGMは当直開始時にフェードアウトします。

## 起動方法

```bash
npm install
npm run dev
```

本番ビルド:

```bash
npm run build
```

## ゲームの概要

- 現実1秒 = ゲーム内30秒
- タイトル画面専用のピアノ入りアンビエントBGM + 心電図モニター音（再生ON/OFF対応）
- 医学生向け: 国試頻出疾患と救急初期対応の基本を中心とした50例
- 研修医・医師向け: 鑑別、蘇生、専門科連携まで扱う実戦的な50例
- ショート当直: 22:00〜翌03:00（現実10分）
- フル当直: 17:00〜翌08:00（現実30分）
- フル当直は一時停止に対応
- 一時停止メニューから「当直を続ける」「セーブして戻る」「終了する」を選択可能
- 保存したフル当直は、同じ端末・ブラウザのタイトル画面から再開可能
- 症例完遂で「褒め」ポイント
- 受入拒否・患者急変で「残念」ポイント
- スコアが +5 を超えるとフィーバータイム
- スコアが −5 に達するとゲームオーバー

フル当直の進捗はブラウザの `localStorage` に保存されます。ブラウザのサイトデータを削除すると保存内容も失われます。

掲載内容は学習用のシミュレーションであり、実際の診療判断には使用しないでください。

## 音源クレジット

- 心電図SE: [「心電図が」](https://dova-s.jp/se/detail/162) / 稿屋 隆（DOVA-SYNDROME）
- アンビエントパッド・ピアノ: Night-ER用オリジナル音源（Web Audio APIによる生成）
